# Supported MCUs
Cirkit Designer supports simulation of several popular microcontrollers. Select an MCU below to learn about its simulation capabilities, supported peripherals, and getting started guides.
| | Platform | Description
| [/docs/platforms/arduino-uno](/docs/platforms/arduino-uno) Arduino Uno | ATmega328p-based board, the most popular in the Arduino family
| [/docs/platforms/arduino-mega](/docs/platforms/arduino-mega) Arduino Mega 2560 | ATmega2560-based board with 54 digital pins, 16 analog inputs, and 4 serial ports
| [/docs/platforms/raspberry-pi-pico](/docs/platforms/raspberry-pi-pico) Raspberry Pi Pico | RP2040-based board with dual-core ARM Cortex-M0+ and PIO
| [/docs/platforms/esp32-s3](/docs/platforms/esp32-s3) ESP32-S3 | WiFi-enabled dual-core Xtensa microcontroller by Espressif
