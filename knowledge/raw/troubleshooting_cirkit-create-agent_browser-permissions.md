# Browser Permissions
When you first use the Cirkit Create Agent, your browser may ask for permission to allow Cirkit Designer to connect to it. If you accidentally clicked Block or Deny, the agent will not be able to communicate with the web app — even if the agent is running correctly.
This is the most common cause of "agent not found" issues, especially for first-time users.
## Fixing Permissions in Google Chrome[#fixing-permissions-in-google-chrome](#fixing-permissions-in-google-chrome) ​
- Open Chrome and navigate to [https://app.cirkitdesigner.com](https://app.cirkitdesigner.com) app.cirkitdesigner.com
- Click the lock icon (or tune/settings icon) in the address bar, to the left of the URL
- You'll see the permissions listed right there — find any that are set to Block
- Change any blocked permissions back to Ask (default) or Allow
- Reload the Cirkit Designer page
If you don't see the permission listed in the dropdown, click Site settings to view all permissions and reset any that are blocked.
## Fixing Permissions in Microsoft Edge[#fixing-permissions-in-microsoft-edge](#fixing-permissions-in-microsoft-edge) ​
The process is nearly identical to Chrome:
- Navigate to [https://app.cirkitdesigner.com](https://app.cirkitdesigner.com) app.cirkitdesigner.com
- Click the lock icon in the address bar
- Click Permissions for this site
- Reset any blocked permissions to Ask (default)
- Reload the page
## Fixing Permissions in Firefox[#fixing-permissions-in-firefox](#fixing-permissions-in-firefox) ​
- Navigate to [https://app.cirkitdesigner.com](https://app.cirkitdesigner.com) app.cirkitdesigner.com
- Click the lock icon in the address bar
- Click Connection secure > More Information
- Go to the Permissions tab
- Review and reset any permissions that are set to Block
- Close the dialog and reload the page
## Still Not Working?[#still-not-working](#still-not-working) ​
If you've confirmed permissions are correct and the agent still won't connect, proceed to the [/docs/troubleshooting/cirkit-create-agent/universal-fix](/docs/troubleshooting/cirkit-create-agent/universal-fix) Universal Fix.
